# JSON на ленту

Детская камера с моментальной печатью по USB не становится принтером. Mac видит флешку или веб-камеру, а термоголова слушается только самой камеры. Напечатать JSON можно так: собрать из него чёрно-белый JPEG с крупным текстом, положить файл в альбом и нажать кнопку печати на корпусе.

Экран умеет:

- разобрать JSON из вставки или файла;
- разрезать его на кадры 3:4, квадрат или длинную ленту;
- убрать серые края букв, чтобы термопечать не превращала текст в кашу;
- скачать baseline JPEG, который понимают такие камеры, как VTech KidiZoom.

## Запуск

```bash
npm install
npm run dev
```

Открой [http://localhost:3000](http://localhost:3000).

Проверка раскладки кадров:

```bash
npm test
```

## Как напечатать с Mac

1. Вставь JSON и скачай JPEG.
2. Вставь в камеру карту памяти и подключи её кабелем. Без карты многие модели видны только как веб-камера.
3. Скопируй файл на карту.
   - VTech KidiZoom: диск `VTech 5491`, папка `DOWNLOAD/PHOTO`. Нужен обычный baseline JPEG.
   - Остальные камеры: папка `DCIM`.
4. Безопасно извлеки диск. На камере открой снимок в альбоме и нажми кнопку печати.
5. Если файла в альбоме нет, камера печатает только то, что сняла сама. Кнопка «На экран» открывает белый лист: сфотографируй его камерой и сразу получишь отпечаток.

В «Системных настройках → Принтеры» такой камеры нет. Это ожидаемо: печать запускается кнопкой на корпусе, а не из диалога печати macOS.
