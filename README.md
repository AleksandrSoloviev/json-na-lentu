# JSON на ленту

Детская камера с моментальной печатью по USB не становится принтером. Mac видит флешку или веб-камеру, а термоголова слушается только самой камеры. Напечатать JSON или обычный текст можно так: собрать из него чёрно-белый JPEG с крупным текстом, положить файл в альбом и нажать кнопку печати на корпусе.

Экран умеет:

- разобрать JSON из вставки или файла;
- напечатать произвольный текст: записку, список, сообщение;
- открыть снимок экрана Mac в TIFF (полное разрешение) и обычные картинки: PNG, JPEG, WebP, GIF, BMP;
- ужать картинку до ширины ленты, сохранив пропорции, и для тёмного оформления сделать чёрный текст на белом;
- разрезать длинный JSON или высокий снимок на кадры 3:4, квадрат или ленту;
- собрать свиток колонкой: буквы на фото повёрнуты на 90°, потому что камера сама поворачивает снимок и обычный текст печатает строкой. На ленте строка идёт от длинного края к длинному, а ширина файла — длина колонки;
- убрать серые края, чтобы термопечать не превращала картинку в кашу;
- скачать baseline JPEG с именем PHO00000.JPG, которое понимает камера.

## Запуск

```bash
npm install
npm run dev
```

Открой [http://127.0.0.1:43123](http://127.0.0.1:43123).

Проверка раскладки кадров:

```bash
npm test
```

## Как напечатать с Mac

1. Вставь JSON, напиши текст или перетащи снимок (TIFF, PNG, JPEG). Для длинного текста выбери «Свиток». Скачай PHO00000.JPG и не переименовывай файл.
2. Вставь в камеру карту памяти и подключи её кабелем. Без карты многие модели видны только как веб-камера.
3. Скопируй файл на карту.
   - VTech KidiZoom: диск `VTech 5491`, папка `DOWNLOAD/PHOTO`. Нужен обычный baseline JPEG.
   - Остальные камеры: папка `DCIM`.
4. Безопасно извлеки диск. На камере открой снимок в альбоме и нажми кнопку печати.
5. Если файла в альбоме нет, камера печатает только то, что сняла сама. Кнопка «На экран» открывает белый лист: сфотографируй его камерой и сразу получишь отпечаток.

В «Системных настройках → Принтеры» такой камеры нет. Это ожидаемо: печать запускается кнопкой на корпусе, а не из диалога печати macOS.
